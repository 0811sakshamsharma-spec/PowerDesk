## 🔍 How to Use PowerDesk

Open the app to see your main drive contents. Use the top bar to type a file path or search for specific items. The left sidebar shows your favorite folders and drives. Right-click any file to see options like rename, delete, or copy. You can drag and drop items between different windows to move them quickly.

No, PowerDesk only reads and writes files based on your commands. It does not modify Windows core settings.

**Is it safe to use?**
Yes. You can review the code since this project remains open-source.

**How do I update the application?**
Check the link above periodically for new releases. Download the new installer and run it to update the app.

**What do I do if the app freezes?**
Close the program and open it again. PowerDesk keeps your data safe because it acts as a viewer for your existing disk contents.

## 📝 Troubleshooting

If you encounter issues during installation, check your Windows security settings. Sometimes Windows SmartScreen prevents new apps from running. If a blue box appears before the install, click "More Info" and then select "Run anyway."

If the application fails to open, verify that you possess an active internet connection to finish any background setup tasks. You may also check that no other version of PowerDesk is attempting to run at the same time.
